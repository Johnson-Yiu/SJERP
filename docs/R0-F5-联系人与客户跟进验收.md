## 改动范围

联系人列表将客户上下文、联系信息、主联系人状态和操作分组；提供可保存到 URL 的搜索/客户筛选及分页，长姓名/职位支持换行，窄桌面保持行操作可达。新建/编辑表单按所属客户、身份、联系方式和备注组织，加入重复联系人提示、可访问名称和保存期间防重复/关闭。详情沿用统一详情组件，保留客户及跟进关联入口和返回筛选状态。

跟进列表将客户/联系人、跟进时间、主题/方式、沟通/回复、下一步/日期分组；搜索、客户/方式、日期、排序、待跟进条件可见并在 URL 中恢复。表单明确呈现设置、保留和清除下次跟进计划的既有语义，富文本编辑器/组合输入可访问名称；保存期间防止重复提交或关闭。附件既有记录与删除确认仍使用原有机制；没有改动文件授权或数据范围。

通用资源页增加 CRM 本地列表过滤、详情文本摘要和重复联系人提示 helper，完善错误/重试、URL 恢复、筛选空状态及请求竞态处理。没有新增另一套联系人或跟进表单/详情系统。
