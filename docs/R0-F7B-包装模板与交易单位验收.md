## 优化内容

- 包装：搜索/尾货/启停/排序 URL 恢复，详情及关联 SKU URL 恢复；持久加载错误与刷新重试；关联列表显示基础单位、各 SKU 数量/重量及验证状态。复制先打开可编辑草稿，保存前不创建模板。尺寸变更对已关联 SKU 的验证影响有确认，未改历史快照。
- 包装表单：统一未保存与 saving 守卫，遮罩、关闭、取消、路由和重复提交受保护；失败保留输入和中文字段错误；1024 标题按钮换行、表格局部滚动和固定操作列。
- 交易单位：复用 SKU 选择器，选中 SKU 与返回路径可恢复；明确“1 卷 / 箱 = N 基础单位”、通用/供应商专用、小数数量、默认与启停。不可变字段只读，编辑备注不重发定义；失败重试、切换未保存确认、保存锁和重复配置提醒。
- SKU 包装：内联建模板与父表单共享保存保护；错误不清除原关联；说明“带入表单后仍需保存 SKU”。打开时净重优先取实际 packaging profile，与数量一致。交易单位返回可重新打开原 SKU 编辑器并保留列表筛选。既有批量填充/撤销算法不改。
