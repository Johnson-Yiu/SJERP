# 小团队首发操作指南

## 登录与报障

业务用户用管理员交付的 HTTPS 地址打开「登录森爵管理系统」，输入分配的账号和密码。登录后从侧栏进入获授权的模块。缺少菜单或显示权限错误时，请管理员核对角色和数据范围。网页打不开、登录失败或提交后结果不明时，记录时间、页面、单号及错误提示。先查看该单据是否已经保存，再决定重试。报障材料应脱敏。

管理员按 [O1 本地运行交接](LOCAL-RUNTIME.md)准备运行环境、核查服务与备份。工作树、库、媒体目录和访问地址要对应同一个实例。首次迁移、升级及恢复按 O1 的运行身份和位置执行。Windows 演示和隔离环境见[根 README](../../README.md)。正式 HTTPS 地址与目标环境仍待配置和验收。

## 导入前先选路径

| 资料 | 从哪里开始 | 写入结果与复核 |
| --- | --- | --- |
| 客户等主档 | 「数据导入」选择「客户」「产品」或「SKU」，下载页面生成的 CSV 模板。客户用原客户编号和名称，产品先核对分类。 | 预览新增、更新和错误行，确认后再执行。更新可能覆盖原字段。到对应主档按编号查结果，结果不明先核查记录再重新预览。 |
| 尚未发生的新销售业务 | 「数据导入」的销售订单入口点击「下载销售订单 XLSX 模板」。准备来源订单编号、客户编号、日期、币种、SKU、交易单位、数量和单价。 | 同一来源编号的明细合成一张销售订单草稿。校验后确认导入，到「订单管理」核对草稿。导入本身不确认订单、占库存、生成应收或发货。 |
| 已发生的历史订单、计划及资金资料 | 「历史资料承接」下载当前历史资料模板。只检查文件可进入「历史资料预检」。准备来源组、原编号、状态、币种及凭证。 | 预检后按来源组审核和归档。到「历史资料承接」核对组状态、错误及来源映射，到「历史订单分析」查询。修正阻断后按原组处理，提交结果不明先查状态。归档不会生成正式资金、库存或履约。 |
| 历史商品关联正式 SKU | 已归档后，在「历史资料承接」打开对应申请和来源组，在页面上方展开「历史商品关联」，核对历史型号、规格、单位与目标 SKU。 | 回看历史商品关联状态和审计。规格或单位冲突时先核实原资料。关联不会生成资金、库存或履约。 |
| 未结余额、库存基准、剩余履约与实际资金 | 在「历史资料承接」按已归档来源办理对应接续，准备核实后的原币余额、盘点和归属证据、剩余行及银行凭证。 | 分别核对获批的余额、库存、接续单或资金事实。剩余履约形成的草稿仍需走正常确认、下单和履约。已有收发货和收付款不得重复登记。 |

字段、对账和正式导入条件见 [D1 导入交付与操作说明](../uat-evidence/history-import-delivery-01/README.md)。以目标系统下载的模板为准。D1 的合成样例只用于专用隔离库，包含在测试中标为「真实」的合成工作簿，严禁进入正式库。目前没有用户真实文件，真实资料适配、试导对账及正式导入授权均待完成。

## 日常操作索引

| 业务 | 从哪里开始与需要的资料 | 完成后去哪看，失败怎么查 |
| --- | --- | --- |
| 客户与跟进 | 「客户管理」核对客户编号和名称，「联系人」维护联系方式，「跟进记录」选择客户并填写日期、沟通内容和下一步。 | 从客户详情或「跟进记录」回查。保存失败先确认客户、必填项和重复编号。跟进记录本身不会生成报价或订单。 |
| 商品与供应来源 | 在「产品管理」「SKU 管理」「交易单位」维护商品、规格和单位。到「供应商管理」核对供应商及其 SKU 来源，准备供应商货号、报价币种与采购条件。 | 回到 SKU 和供应商详情核对匹配项。找不到来源时先检查 SKU、单位、供应商状态及维护范围。维护资料不会生成采购单。 |
| 报价 | 「报价管理」准备客户、SKU、交易单位、数量、价格和条款。报价详情可用「预览 PI」「导出 Excel」，变更已保存报价用「创建修订版」。 | 核对报价号、明细和所用版本。导出失败先确认保存状态和版本。预览 PI 不保存草稿。需要转单时用「创建销售订单」。 |
| 销售订单 | 从报价详情创建销售订单，或在「订单管理」打开销售草稿。核对客户、SKU、数量、单价、交期和付款条件，再用「确认订单」。 | 回订单详情核对状态，并在「应收计划」核对计划。确认失败按提示检查明细、来源报价状态和业务条件。草稿本身不会发货或登记收款。 |
| 采购与收货 | 在订单详情「采购与发货」选定采购来源后点「生成采购草稿」，或从「采购管理」准备采购草稿。核对供应商、SKU、数量、单位、币种与付款条件，点「确认采购下单」。货到后在采购详情点「验货入库」。 | 回采购详情查收货数量，在「库存流水」核对入库，在「应付计划」核对计划。失败先查状态、剩余可收数量和单位。下单不会替代验货入库，入库不会登记付款。 |
| 发货 | 在订单详情「采购与发货」选择「批量发货」，核对明细、可发数量、发货日期和物流资料，再点「确认发货」。 | 回发货记录与「库存流水」核对。失败先看订单状态、可发数量及库存预留。发货不会登记收款。 |
| 收付款及银行记录 | 从「应收计划」「应付计划」或「财务流水」核对合同、方向、币种和金额。采购详情可用「登记付款」。实际银行事实到「银行资金记录」核对，准备账户、银行日期、实际金额和凭证。 | 分别查看计划、财务流水和银行记录，必要时到「账户余额与对账」核查。失败先核对来源、已核销余额、凭证和既有银行记录。合同汇率不能替代银行实际到账，计划金额不能当作已收付金额。 |
| 查询报表 | 打开「报表中心」选择数据来源、日期及筛选条件，查询结果后按权限导出。经营和财务概览可用于查汇总。 | 复核报表筛选条件、日期口径和金额单位。汇总异常先查下钻和原单，导出失败核对查看与导出权限。查询与导出不会修改业务数据。 |

报价修订保留原报价和直接来源版本。导出时按完整报价号核对文件名与 PI 的 Invoice No.。报价转出的订单先以草稿保存，确认订单时再处理所用报价版本的状态。

### 取消、退款与剩余履约

| 操作 | 入口与资料 | 复核与处理 |
| --- | --- | --- |
| 取消订单 | 「订单管理」打开草稿、已确认或生产中的订单，点「取消订单」，填写原因并确认。 | 回订单详情核对状态、库存预留和应收计划。如有待退款，按实际退款另行登记。被拒绝时按提示核对既有履约、采购或收款。 |
| 从原收款退款 | 在「财务流水」找到原收款，点「登记退款」。选对应订单或适用的未分配预收款，填写实际日期、原币金额及依据，上传凭证后确认。 | 查退款流水、原收款及对应应收。有效订单恢复对应应收，已取消订单应收保持为零。拒绝时核对原币可退余额、订单关联和凭证。结果不明先查原流水。 |
| 终止剩余履约 | 在订单详情「调整订单数量」点「调整数量」，勾选「终止本次选中明细的剩余履约」。选中行新数量填为已发数量，未发货的选中行填 0，填写变更原因、预览影响再提交。 | 核对数量变更记录、应收、库存预留和关联采购。被拒绝时按提示核对已发数量及关联记录。 |
| 核对成本币种 | 产品详情的 SKU 列表显示「币种待核实」时，核对原采购资料或报价，确认后维护成本币种。 | 回列表分别核对成本和售价的币种。资料不足时保留待核实状态。 |
| 未保存保护 | 离开编辑页面或关闭表单时，若出现放弃确认，点「继续编辑」返回保存，或点「放弃修改」离开。 | 保存后重新打开单据核对。结果不明先查原单。 |
