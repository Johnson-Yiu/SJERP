# 报价管理：PI 模板驱动的新建报价与 Excel 导出

## 目标

将“报价管理—新建报价”升级为双栏工作台：左侧编辑报价，右侧实时预览与 `文档/PI模板Proforma Invoice Sunjack Lighting.xlsx` 同结构的 Proforma Invoice（PI）。点击“保存并导出 Excel”后，系统保存报价并下载按该模板生成的 `.xlsx`。

模板中无背景色或黑色文字内容为固定内容，原样保留。模板内红色填充或红色文字为动态数据来源。本期不新增客户税号；PI 的 Tax ID 保持空白。

## 页面与交互

### 新建/编辑报价窗体

- 桌面端为宽屏双栏窗体：左栏约 42% 编辑，右栏约 58% 报价单预览；两栏各自滚动。
- 窄屏时切换为“编辑”和“预览”标签，避免压缩报价单。
- 用户选择客户后，自动带入客户公司名、账单地址、默认联系人、默认联系人邮箱和电话。它们是报价快照，可仅修改本次报价而不会修改客户主数据。
- 左栏包含：客户、报价日期、有效期至、币种、汇率、状态、交期（天）、预付款比例、贸易条款、运输说明、运费、折扣、备注、产品明细。
- 有效期天数由报价日期和有效期至计算，用于 PI 的 `Price Valid Date`。
- 保存按钮名称为“保存并导出 Excel”。成功后关闭窗体、刷新列表并下载文件；若导出失败，报价保留且提示用户重新导出。

### 产品与 SKU 图片

- SKU 管理新增单张产品图片上传/替换/预览入口，图片作为受控媒体文件保存。
- 选择 SKU 时，报价行自动带入 SKU 图片、型号（SKU 编号）、单位、默认单价和产品描述。
- 产品描述取 SKU 可用说明，缺失时回退到产品描述；报价行可改写，保存为报价行快照。
- 报价行支持增删；每行必须有 SKU、数量和单价。图片允许缺失，预览/导出显示空白图片格。

## 报价规则与字段映射

### 编号与金额

- 报价单号由后端在创建时生成，格式为 `SJYYYYMMDDCCNNN`：`CC` 是客户国家/地区的 ISO 3166-1 alpha-2 代码，`NNN` 是该日期当日流水号，从 001 开始。
- 用户可使用正常保存编辑已有报价，但不可修改已生成的报价单号。
- 总金额 = 明细金额之和 + 运费 - 折扣。
- 预付款金额 = 总金额 × 预付款比例；尾款为总金额减预付款金额。
- 金额大写使用报价币种的英文金额文字，在网页预览和 Excel 中共用同一结果。

### PI 模板动态区域

| 模板区域 | 数据来源 |
| --- | --- |
| Buyer Information | 报价快照：客户名称、联系人、地址、邮箱、电话；Tax ID 为空 |
| Date / Invoice No. | 报价日期、后端生成报价单号 |
| 产品明细 | 顺序号、SKU 图片、SKU 编号、报价行描述、数量、单位、单价、行合计 |
| Unit Price / Total 表头 | 当前报价币种 |
| Shipping Cost / Sub Total | 运费、总金额 |
| 金额大写行 | 总金额的英文金额大写 |
| NOTES 1-5 | 交期、有效期天数、预付款比例及金额/尾款比例及金额、贸易条款、运输说明 |
| Seller / Bank / 固定声明 | 保留模板固定内容 |

多个产品时，产品行按模板样式向下复制，合计、金额大写、备注和银行信息整体下移，不覆盖内容。

## 导出与样式

- 后端以现有 `PI模板Proforma Invoice Sunjack Lighting.xlsx` 为源模板生成导出文件，保留固定合并单元格、边框、行列尺寸与静态文字。
- 生成的工作簿所有单元格字体统一为 Arial；所有标题（PI 主标题、买卖方标题、明细表头、银行信息标题）统一为 Arial 粗体。
- 单价、行合计、运费、总额采用对应币种显示，保留两位小数。
- 导出接口仅允许有权限的用户下载对应报价；文件名包含报价单号。

## 数据与接口

- `SKU` 新增图片字段。
- `Quote` 新增买方快照和 PI 条款字段：收件人、地址、邮箱、电话、交期天数、预付款比例、贸易条款、运输说明。
- `QuoteItem` 新增产品描述快照。
- 创建报价接口负责服务端编号生成、快照默认值填充及并发安全的当天流水分配。
- 新增 SKU 图片上传接口与报价 Excel 导出/重新导出接口。

## 验收与测试

- 后端：编号（不同日期和国家/地区）、计算、默认快照、数据校验、导出权限与 Excel 填充测试。
- 前端：SKU 自动带入、编辑即预览、产品行增删、校验与失败提示。
- 生成并视觉检查 Excel：单产品、多产品、无图片、不同币种、运费/折扣及不同预付款比例；确认没有内容裁切、公式错误或布局重叠。
- 对照网页预览和导出文件，检查客户资料、产品、币种、金额、条款、卖方信息和银行信息一致。

## 非目标

- 本期不新增客户 Tax ID。
- 本期不改动卖方资料、银行资料和模板中的固定说明文字。
