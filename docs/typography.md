# 应用界面字号规范

字号变量统一定义在 `frontend/src/styles.css` 的 `:root` 中。页面和组件使用变量，避免新增独立像素字号。

| 层级 | 变量 | 字号 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | `--text-page` | 24px | 页面主标题、详情主体名称 |
| 弹窗标题 | `--text-dialog` | 20px | 弹窗和抽屉标题 |
| 区块标题 | `--text-section` | 16px | 卡片标题、表单分组标题 |
| 正文 | `--text-body` | 14px | 正文、表格、表单、按钮、导航 |
| 次要文字 | `--text-secondary` | 13px | 状态、标签、次要信息 |
| 辅助文字 | `--text-caption` | 12px | 提示、说明、字幕 |
| 统计数字 | `--text-metric` | 28px | 概览卡片中的关键数字 |

正文默认行高为 1.5；标题按层级采用 1.3–1.4。空间不足时优先调整布局、换行或滚动，不再通过缩小表格和操作文字解决。

顶栏使用页面标题；内容区的页面标题使用弹窗标题层级，以便与顶栏保持清晰层次。

报价单、发票等固定版式及用户编辑的富文本内容保留自身排版规范。
