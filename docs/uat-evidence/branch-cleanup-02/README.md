### 恢复记录

删除前在独立审计仓库保存 `refs/recovery/branch-cleanup-02/<原分支名>`，逐条还原到 `refs/restore-check/branch-cleanup-02/<原分支名>`，核对提交 SHA 与提交树。其后从独立 E 盘开发克隆复核 51 个原始 SHA 的提交树。恢复引用也可由任何具有同一 master 历史的克隆按清单重建，因为每个已删除 SHA 均为当前 master 祖先。

恢复时先确认原远端分支名未被重新使用。用 `git merge-base --is-ancestor <原SHA> <已核验的master>` 和 `git rev-parse <原SHA>^{tree}` 复核，按结果表恢复引用核对后，才可获授权向原分支名推送。演练在本地恢复命名空间完成。
