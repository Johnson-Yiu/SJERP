## 最小接收范围与验证次序

- 本模块暂无已证实缺失且必须上线前接收的历史生产改动。优先演练入库冲销和销售出库重放、共享采购费用与应付边界、旧采购快照再打开。沿用 PostgreSQL 隔离测试与合成库存，不接真实帐套。
- 如采购人员要求消除分数单位 MOQ 误报，最小范围仅当前采购草稿判断及定向测试。旧版算法同样存在误报。
- 若需保留旧采购库存慢响应 Chrome 场景，只移植断言到当前测试文件，避免引入旧数据库准备脚本或重复 runner。原生 Excel 实机分页待现场参数明确。
- 涉及迁移时沿现行叶子，优先逐字段确认立项价值。旧 MOQ 0078、SKU 0078、ISS-021 0078 均已有后继。团队的试点库如果确实曾应用旧分支迁移，只在隔离数据副本上验证迁移记录与表列，确认存在缺口后再拟专门前向迁移。
