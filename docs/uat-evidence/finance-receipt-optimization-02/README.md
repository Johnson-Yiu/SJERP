## 结论与已修复内容

收款支持未选订单默认 USD、订单币种优先、可空账面参考汇率、明细扣减、授权非现金抵减和多订单核销。实际到账、客户汇款、核销额度与结汇额度分别保留。原订单已有优惠只作依据记录；客户承担和待核实差额保留应收。金额使用 Decimal，历史金额不改写。

已修复 PostgreSQL 对可空关联执行 FOR UPDATE 导致多订单分配失败；收款已结清后同请求重试被计划状态或凭证重复校验拒绝；缺参考汇率被默认1折算；未分配收款汇总和明细口径不一致；原收款详情缺少稍后结汇入口；内联结汇首次挂载未生成事件身份；内联来源金额不可编辑；核销关联订单显示遗漏；详情布局和遮挡。

订单利润现在包含已归属订单的我方收款手续费，并扣除核准非现金应收抵减。已计入订单金额的优惠不生成额外抵减。手续费和抵减不会另造现金流水；未归属订单的手续费不猜测分摊。财务概览与其明细分别列明费用和非现金抵减，实际人民币资金仍只统计已确认净到账。

## 整个记账模块复查矩阵

以下是代码、已有服务和定向验证的能力边界；并非所有业务均已从普通记账窗口闭环。

| 业务 | 当前能力及复用 | 剩余缺口/操作边界 |
| --- | --- | --- |
| 客户正常、分次、一款多单、超额收款 | 本包原币收款、PaymentPlan、AdvanceAllocation；实收与手续费核销分开 | 超额保留可核销余额；不扩大结汇或普通退款现金上限 |
| 优惠、抹零、手续费、未知差额 | FinancePlanWriteoff、FinanceVoucher、权限与审计；客户承担/待核实不抵减 | 已核准抵减后的反向更正仍安全拒绝直接作废，缺少抵减撤回链；需继续补修，不覆盖原记录 |
| 部分、分次、多款结汇 | 复用 RmbCashEvent/CashSourceAllocation、私有凭证、预览、确认、查重 | 原收款入口限定本收款家族；多款合并沿用已有资金事件来源选择器；普通流水内直接多款选择仍非同一表单 |
| 供应商定金、分期、尾款、预付抵扣 | record_contract_payment、采购付款计划、allocate_advance | 普通付款窗口选一张采购单；一款多采购单须先记未分配预付款再逐笔分配，直接多单入口仍有缺口 |
| 订单费用：样品/打样/模具/验货/运费/报关/仓储/佣金 | 订单费用、样品和运费类型；详细用途可写备注；采购附加成本及既有分摊服务保留 | 未建立同一费用凭证跨流水与采购附加成本的唯一来源绑定，不能宣称自动防止重复归集；勿将同一发票同时作为两笔成本 |
| 工资、办公、差旅、推广和期间费用 | 现有类型及发生日期；未改其他类型 CNY 默认 | 期间按发生日期筛选；没有另外的权责期间调整流程 |
| 员工垫付、公司预借、报销 | 目前只有普通费用/其他收支可记录金额 | 缺少人员往来、原垫付与报销关联及只归集一次的校验；不把备注当作实现，不建议用普通费用重复登记两次 |
| 可退押金及退回 | 普通收支可记金额 | 缺少可退本金、待收回余额和原记录关联；普通费用不能正确表达押金性质 |
| 设备购置 | asset_expense 记录实际付款和用途 | 不代表固定资产台账/折旧；按用户要求延期 |
| 原收付款退款 | record_contract_refund 按合同已收/已付现金上限回退计划；保留拆分和作废链 | 当前从合同选择，非精确原收款选择；已有银行事件时按原保护拒绝猜测来源；商业补偿不能混用原款退款 |
| 商业退款批准与实际扣款 | FinanceInstruction/FinanceReview/FinanceFact 的批准、实际支付、凭证及来源额度已有服务 | 普通流水尚未统一接入批准与实际扣款步骤；不要把批准当作现金已付 |
| 银行退回 | finance_closeout.bank_return 追加原银行事实的反向关系 | 银行事实反向不等于原订单核销恢复；按原核销逐项恢复应收应付的流水统一入口和映射仍有缺口 |
| 录入更正 | 普通流水作废留原记录；账户资金更正为追加链并要求独立复核 | 普通流水更正与账户更正是两层；有抵减或银行事实依赖时不能用作废强行绕过 |
| 自有账户互转、取现、现金存银行 | FinanceFact 两端、FinanceTransferMatch、有效本金分类，实际资金汇总排除已匹配本金 | 普通“其他收入/支出”不能替代两端核实；统一流水内两端操作入口仍未接入 |
| 借款、还本金、注资、利息 | 账户事实支持 loan/capital/interest 性质和收支方向 | 普通流水缺少本金性质及借还余额链；不能将本金当收入费用；还款计划尚无专用流程 |
| 税费、退税 | tax_fee 支出，其他收入可记录退税并注明用途 | 尚无专用退税类别与申请对应关系；不代表报税功能 |
| 客户供应商抵账 | 核销与现金记录在服务层分离 | 缺少双边协议依据及跨应收应付的抵账流程；没有实际收付时不得用虚拟现金登记 |
| 汇总与导出 | 原币账面参考、实际净到账、账户余额各自分开；缺参考汇率不按1汇总 | 未录参考的原币余额不进入人民币参考合计；全币种原币余额应在流水逐笔查看 |

上述缺口继续归 ISS-105/ISS-108 的未完成子范围，不关闭已有待独立复审条目。不新增总账、期初/期末、银行导入、折旧、报税或正式 RBAC。
