# 真实样本与历史报价导出核对

## 资料来源与范围

本次独立 worktree 没有经授权的真实历史 XLSX/CSV/报价附件副本。既有 ISS-037 合成测试只能说明已知未知值的保护行为；它不提供实际受影响报价数、客户数、供应商数或导出失败比例。正式抽样状态：未执行。

## 既有合成证据

旧合成测试 `test_quote_unknown_buyer.py` 已覆盖：历史报价买方公司名称未知时，原版及修订版 PI 与 XLSX 导出均返回 422，`fields` 含 `buyer_company_name`；不回落当前客户名称，也不产生 XLSX 文件。

从当前 `quotation_export_dto` 规则可列出需在真实副本中逐字段核对的阻断情形：

| 风险条件 | 当前保护/可能返回 | 影响范围 |
|---|---|---|
| 买方公司名称为空/未知 | PI 与 XLSX 返回 422，字段 `buyer_company_name` | 真实受影响数量未统计 |
| 买方税号快照为 `NULL` | DTO 将其作为未知值处理，拒绝导出并返回买方字段错误；不得从当前主档补造 | 真实受影响数量未统计 |
| 批准保存的买方国家、联系人、开票地址或收货地址在当前模板没有独立位置且有值 | `buyer_unmapped` 返回 422，指出不能由现模板完整表示的具体字段 | 真实受影响数量未统计 |
| 卖方国家、税号、开票/收货地址或收件人扩展资料模板无对应位置 | 主体资料校验返回 422 (`party_details`) | 真实受影响数量未统计 |
| 缺失/不一致的卖方模板快照或无效主体审批记录 | 安全校验拒绝导出，返回主体资料/模板错误 | 真实受影响数量未统计 |

上表根据代码保护条件列风险范围；除买方名称未知外，没有在本包声称对每个条件都完成 API 样本复现。受影响真实样本计数均未知。处理应为保留未知值、列出精确字段、回看原始合同/税务资料并走已批准的主体更正/模板变更流程；不从当前主档填充历史字段，不关闭 422 保护，不用更宽松映射生成误导性 PI。

## 下一轮真实核对记录格式

收到授权副本后在受控环境逐份记录：匿名样本编号、原文件名/格式、期间、来源系统、SHA-256（仅受控附件清单）、报价修订、PI/XLSX 实际结果、HTTP 状态、明确缺失字段、模板映射审查结论、原资料核验人及复核人。禁止在公共报告或普通页面显示完整 SHA、个人税号或请求身份。
