- ten-switches：673 ms。

10次切换未增加请求，未产生业务写入。关闭后工作区面板、Vue挂载实例、window/document 注册数回到单列表基线。DOM 节点数也回到单列表基线。新建参考资料未做跨任务共享缓存，每个新建任务仍需独立加载；12标签上限是明确资源边界，不把表单交给缓存淘汰。

测量局限：只记录 window/document 的 add/remove 注册，不覆盖元素上的全部监听，once 注册可能多计；Vue计数通过开发环境实例树只读遍历，不是生产遥测。timer 包装记录当前页面，不含浏览器、网络线程与操作系统资源。基线已存在的 interval 未单独归因，打开/切换/关闭未增加其数量。JS heap 为瞬时观测，未强制GC，关闭后没有立即回到最初值，不证明进程内存完全释放。截图、测量与完整业务负载压力测试是不同范围。

没有测试浏览器崩溃恢复；内存草稿不能承诺在刷新、浏览器退出或崩溃后恢复。beforeunload 只按浏览器能力拦截，实际取消刷新场景另见身份/刷新专项。
