# 权限、版本和审计核对

## 权限矩阵

| 能力 | `reports.view` | `reports.create` | `reports.update` | `reports.delete` |
|---|---:|---:|---:|---:|
| 查看已发布模板 | 是 | 是 | 是 | 是 |
| 创建草稿 | 否 | 是 | 是 | 是 |
| 查看自己的草稿 | 否 | 是 | 是 | 是 |
| 查看全部草稿及完整审计 | 否 | 否 | 是 | 是 |
| 编辑/发布/取消发布 | 否 | 否 | 是 | 是 |
| 删除模板 | 否 | 否 | 否 | 是 |

以上是共享模板动作权限；每次使用模板仍会重新执行报表来源、维度、筛选字段、数据范围和当前用户权限校验。开发环境身份按项目约定通过服务端 `development_superadmin_enabled()` 统一处理。

## 已验证边界

1. 普通用户不能创建、编辑、发布或删除模板，但可使用已发布模板。
2. 草稿不出现在普通用户列表中；取消发布后普通用户列表为空。
3. 取消发布后，带 `shared_template` 的报表 URL 不会继续读取旧模板配置。
4. 重复提交旧 `config_version` 返回冲突，服务器不会静默覆盖新版本。
5. 模板删除的审计记录在删除后仍保留，包含删除前快照；非管理用户不能读取配置快照。
6. 不合规的来源、分组、重复维度、时间过滤和未知字段由服务端拒绝。
7. 同一销售模板由 `self` 数据范围员工查询时仅返回本人客户的 100；由同部门数据范围员工查询时返回两个合法客户、300/2 单，证明模板不会以发布者身份执行查询。
8. 没有采购查看权限或财务流水查看权限的员工，不能使用已发布的采购模板或银行实际资金模板；撤销 `reports.view` 后列表和查询立即拒绝。

## 审计动作

本轮覆盖：`创建团队共享模板`、`修改团队共享模板`、`发布团队共享模板`、`取消发布团队共享模板`、`删除团队共享模板`。审计范围按当前用户可见模板过滤，模板不存在或已删除时不向普通用户泄露配置内容。
