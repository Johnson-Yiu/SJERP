截图由 Codex 内置浏览器 `tab.screenshot()` 原始 JPEG 字节直接保存，没有图像编辑、拉伸、拼接或重编码，没有 CDP、外部浏览器或截图代理。普通 `fullPage:false` 在有滚动条时实测可能得到比 DOM 视口少 15px 的图片；这些不匹配捕获未覆盖合格归档。本轮使用同一受支持 API 的 `clip:{x:0,y:0,width,height:1000}` 精确截取完整请求视口；这是正常截图接口，没有绕过安全拒绝。部分无滚动条状态使用 `fullPage:false`，两种方法均核对原始像素。

请求宽度 1440、1280、1024，高度1000，DPR1。每张校验请求、DOM、原始 JPEG 尺寸及文件名，生成 SHA-256。见 [截图清单](SCREENSHOTS.md)、[最终元数据](manifest.json)、[捕获记录](capture-records.json)。捕获记录含同名状态重拍历史；清单以最终文件为准。数据条数随实际新增操作变化，不能据此认定业务数据不一致。
