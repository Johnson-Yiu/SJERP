# 仍需补验的状态

以浏览器截图索引中的具体状态、原生缩放、实测或模拟标记为覆盖依据。未列入索引的同模块状态仍在下列范围内。

- 产品和 SKU。销售型号前缀影响预览、确认及拒绝，SKU 动态属性组合全流程、重复候选、批量包装和撤销、版本历史、SKU 图片替换及移除，供应绑定编辑、偏好切换及其采购回填。
- 分类与参考资料。拖动改层级、继承覆盖、重排确认，产品参数保存重开、包装尾货策略及共享箱规变更、HS 编码批量产品分配、交易单位新增／停用及历史快照。
- 采购。所有业务状态在六档尺寸组合的完整覆盖；多订单与多种交易单位的交叉状态、不同收货地点重复写入、超到、冲销、取消、已收齐和只读采购、错误后的焦点及关闭恢复。库存恢复沿用其现有证据边界。
- 库存。手工调整提交、不同来源的只读与冲销、关联抽屉全部标签和内部滚动、同一 SKU 多仓不同批次的筛选及导航。库存流水里的位置字段与收货位置字段是两个独立入口。
- 通用。所有页面的加载、重新加载、异步提交中、服务端校验、受控网络拒绝、所有未保存确认路径、键盘操作、附件更换和删除。受限普通员工、真实 PostgreSQL、打印成品与分页、全量及部署验收均需对应任务和证据。
- A2 固定候选。按发布后的实际 SHA 对采购详情及共用外壳复测，记录原生缩放与截图。资金流程、采购付款及应付计划由 A2 验收。

本轮已通过的子流程包括产品查询无结果、分类级联和未保存确认、证书真实校验与附件保存回显、采购草稿编辑入口、指定仓库与批次的部分收货，以及两张订单的采购成本归属保存。产品受控刷新 500 的错误提示与重载操作仍未取得可用截图。详见 [定向复验索引](browser-verification.json)。
