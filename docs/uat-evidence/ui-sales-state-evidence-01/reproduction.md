### 实际横移复核

进入相同空明细编辑器并等待进场动画结束。以 390×844、100% 调用 Chrome 页面内的 `window.scrollTo(10000, 0)` 模拟水平滚动。滚动后页面标题、菜单和工作区标签从画面左侧移出，报价编辑器和底部动作仍留在视口。见 [滚动前](supplemental/Q02R-390-100.png) 与 [滚动后](supplemental/Q02X-390-100.png)。由此可复核整页可横移，而非仅有表格容器局部滚动。保持待独立复审。

## 发货与主体审批复核

默认仓库存校验可通过合成订单复现。进入四条明细的已确认订单，开始生产，进入履约并打开批量发货。只选首条明细，填写 2 件，保持默认仓。真实接口返回 400，表单显示「所选仓库及批次库存不足，不能确认发货」。勾选「指定出库仓库和批次」，选择自有仓并填写合成仓库名称后，真实接口返回 201。随后冲销返回 200，重新打开履约页可见「已冲销」。候选位置为 `OrderDetailModal.vue` 发货表单和 `services/fulfillment.py` 仓库校验。此项按业务规则留证。[窄屏校验](stable-recheck/O07-location-validation-390-125.png) · [窄屏冲销后](stable-recheck/O08-reversed-390-125.png)。

主体更正画面可见申请和审批账号 ID、时间与理由，留给复审判断展示内容。取证中只使用合成账号和资料。[审批前](party-complete/Q07-review-390-100.png) · [审批后](party-complete/Q07-approved-390-100.png)。
