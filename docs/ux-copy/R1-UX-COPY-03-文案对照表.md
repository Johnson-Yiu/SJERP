## 状态与边界

- 空数据、加载中、加载失败和无权限继续使用现有的不同状态组件与 `role=status` / `role=alert` 语义；本次没有合并这些状态。
- “账面收入 / 支出”“人民币折算参考”“待结金额（人民币折算参考）”均没有改动原有计算。
- “银行实际人民币资金”只沿用现有已确认银行事件的统计范围；没有扩展为公司全部银行账户余额。
- 退款、反向更正和历史资金归属只作边界提示，没有新增功能承诺。
- 库存“待采购”仍是当前数据计算的参考缺口，不触发采购单，也不改变库存计算。
