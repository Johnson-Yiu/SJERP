# 仓库与财务升级说明

本次沿用现有 Django、Vue、SKU、采购单、订单、库存流水和收付款计划，在原框架内升级。面向按单采购、少量现货的贸易业务，财务定位为经营收支台账，不增加总账科目、凭证审核等完整会计系统。

## 日常操作

### 一笔订单怎么走

1. 确认销售订单。系统按 SKU 预留已有现货，显示待采购缺口。
2. 在采购管理创建采购单，选择供应商、关联销售订单、SKU、数量、单价及币种。少量备货可不关联销售订单。草稿不计入在途和正式应付。
3. 到货后打开采购单的“操作 → 验货入库”。核对型号、数量和外观，只填写合格入库数量。破损、拒收、待补货等情况写入备注，未验收数量继续保留为待到货。
4. 系统同步库存、采购在途和关联订单预留。分批到货可以多次登记。
5. 在订单详情的“采购与发货”登记实际发货数量。系统扣减实物和本单预留，保护其他订单预留；全部发完自动标记已发货。
6. 查看应收/应付计划并登记实际收付款。日常办公、工资、银行手续费、物流等支出在财务流水中分类记录。

零库存是正常状态。“待关注”只统计采购缺口或数据异常，不要求给所有 SKU 建立安全库存。

### 收付款怎么记

- **已有销售合同的收款**：财务流水选择“客户收款”并关联订单，或直接在应收计划登记。
- **采购付款**：采购单的“登记付款”或财务流水的“供应商付款”。从合同入口付款时，自动依次核销定金、尾款等计划。一次付清整单不会把尾款误留为未付。
- **先收到/付出款，暂不确定归属合同**：选择未分配预收款/预付款，指定客户/供应商。之后在流水列表点击“核销”，只能分配到相同往来方、币种和收付方向的待结计划。
- **超额收付款**：自动拆成合同核销部分和未分配预收预付部分。拆分记录表示同一笔实际收付款的构成，不要再重复记一笔总金额。
- **记错款项**：对原始流水点击“作废”，其拆分记录一同作废，核销余额同步撤回，原记录保留。随后重新登记正确记录。已确认或已作废流水不能直接覆盖、删除或重新激活。
- **更改付款安排**：在应收/应付页面“调整计划”修改日期、备注和未使用计划金额。已有核销记录的计划只能调整日期与备注。修改分期比例时，先调低原计划，再调高另一笔，避免计划合计超过合同。
- **汇率**：实际登记时填写实际采用的对人民币汇率；人民币汇率必须为 1。计划结算表单会带出合同汇率。来源报价中的定金比例会沿用到销售订单；无报价时默认 30%/70%，可调整。

### 每月看什么

财务概览支持开始/结束日期、月度现金收支、分类汇总及 CSV 导出。

| 指标 | 口径 |
|---|---|
| 期间实际收入/支出 | 所选日期内、已确认流水的人民币金额，包含预收预付，排除作废记录 |
| 净现金流 | 同期收入减支出；不是利润，也不是银行账户余额 |
| 应收/应付 | 当前有效合同待结计划，按合同汇率折算人民币；不随所选报表日期回溯 |
| 未核销预收/预付 | 当前预收预付款减去已分配金额，按原流水汇率折算 |
| 月度销售额 | 本月非草稿、非取消订单金额，按合同汇率折算；不是本月实际收款 |
| 订单预估毛利 | 合同金额减关联有效采购金额及订单费用，属于经营估算，不是正式会计利润 |

预收预付的核销只改变合同归属，不重复增加现金流水。订单工作台可查看核销明细与来源流水号。

## 已修正的问题

| 范围 | 原问题 | 本次处理 |
|---|---|---|
| 在途 | 使用所有历史到货扣减当前未完成采购，可能变成负数 | 按未完成采购明细分别计算非负待到数量 |
| 预留/发货 | 发货后预留未释放、重新分配仍按原始订单数量 | 只预留未发部分，发货后同步释放与重算 |
| 跨订单库存 | 发货可能占用其他订单已经预留的货 | 发货只允许使用本单预留和公共可用库存 |
| 采购缺口 | 已发数量、已到货和重复 SKU 可能造成重复扣减或虚假缺口 | 纳入未发需求、预留及在途，并在重复 SKU 行之间分配采购覆盖量 |
| 手工库存 | 零数/负数、批量超扣、改删已消耗入库可能破坏余额 | 增加校验、事务回滚和可用库存保护；采购入库/销售出库只能从业务单据生成 |
| 状态 | 草稿/取消单仍可能到货、发货或收付款 | 增加服务层与接口状态限制 |
| 合同变动 | 有履约或收付款后仍可能重写商品、客户/供应商、金额 | 保护已有业务依据；无业务历史时同步未使用计划 |
| 收付款 | 整单付款只核销第一笔计划，余款误变为未分配款 | 合同入口依计划顺序核销，真正超出的部分才转预收预付 |
| 预收预付 | 缺少分配明细、方向校验及作废回滚 | 新增核销明细，记录金额、计划及是否撤回；作废同步还原 |
| 财务汇总 | 作废款计入小计、多币种直接相加、计划汇率默认 1 | 排除作废款，按人民币汇总，带入合同汇率 |
| 分页 | 页面仅取前 50 条，汇总和选择器可能漏记录 | 库存、采购、计划、流水及相关选择器读取全部分页 |
| 数据导入 | CSV 可以直接覆盖已有流水，绕过核销 | 禁止覆盖已有财务流水，通过统一校验及记账服务导入新流水 |
| 旧记录兼容 | 旧版销售出库没有发货单明细，订单进度可能漏计 | 保留旧版出库统计，避免与新发货单重复计算 |

## 保持轻量的边界

- 仓库仍为 SKU 汇总库存；仓库名称可记录，但本次没有建设分库位的独立库存账、批次、序列号或扫码系统。
- 验货采用“合格数量入库 + 异常备注”。没有独立质检隔离库、全拒收单、供应商退货审批流程。全部拒收时不要登记合格入库，保留采购待到货并在采购单备注跟进。
- 客户退款/供应商退款可记录实际现金变化，但不会自动重写合同金额或原计划。退货、折让、取消合同等需按实际协议核对合同、库存和收付款计划；本次未增加完整退货贷项单流程。
- 新增订单费用、采购成本及预收核销可以追溯，但不计算正式存货计价、成本结转、未实现汇兑损益、税务报表或资产负债表。
- 沿用现有权限架构。没有新增自动银行对账、支付接口或对外转账能力。
- 事务和前端保存状态能降低重复操作风险，但没有新增跨网络重试的业务幂等键。遇到请求结果不明，应先查询是否已入账，再决定重试。
