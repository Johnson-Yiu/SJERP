# 报表中心与图表块

入口：左侧「报表中心」，地址 `/reports`。基于现有 Vue / Django 架构增量实现，无新增前端依赖。

## 已实现

- 销售、采购与供应商、客户增长、现金收支、库存变动五类统计源，16 个常用预置块。
- 按模块选择订单日期、预计交期、预计到货日、流水发生日期、创建时间或更新时间。
- 自定义起止日期（含结束当天）；今天、本周、本月、本季度、本年、上月、去年、近 30 / 90 天快捷范围。
- 日、周（周一）、月、季度、年分组，缺少业务的时间段补零；最多查询十年。
- 上一等长期间和去年同期比较；基期为零不伪造增长率，闰日去年同期按 2 月 28 日处理。
- 按适用模块提供区域、国家、客户、供应商、产品、SKU、主分类、负责人、来源、状态、原币币种、收支方向、业务类型、仓库、出入库类型。
- 不同维度的筛选可叠加；点击分组后切换维度继续分析。同一维度当前选择一个值。
- 折线图、条形图、环形图、分页数据表、全量 CSV 导出。非时间图显示绝对值前 12 项，表格与导出保留全部分组。环形图只表示显示项目内的比例，负数自动使用条形图。
- 保存、排序、移除自定义图表块；保存模块、维度、指标、日期口径、比较方式、默认图形和附加筛选，起止日期跟随报表中心。设置保存在当前浏览器，最多 30 块，不是跨账号 / 跨设备共享看板。
- 客户增加业务区域，供应商增加国家/地区与业务区域；通过原有档案表单维护。

## 统计口径

所有金额使用服务端 Decimal 聚合，原币通过单据保存的人民币汇率转换，不直接混加多币种。

销售排除草稿和取消单。客户、国家等维度的销售金额包含运费减折扣；产品 / SKU / 主分类分组将其列入「订单调整（运费 / 折扣）」，确保汇总可核对。筛选具体产品后仅包括匹配货品金额，不暗中把整单运费分摊给产品。采购统计货品金额，不含附加费用，亦不代表付款或实际到货。

单据数在每个分组及总计中分别去重；同一单据可能包含多个产品，所以不能把各组单据数相加当作总单数。不同数量单位分别展示，数量图每次选择一个单位。销售数量优先使用成交单位快照；采购和库存单位使用 SKU 当前单位。

现金流仅统计已确认流水，收入为正、支出为负，优先使用实际人民币金额，否则按流水汇率折算；预收预付的非现金分配不再计入现金流。库存报表是选定期间的净变动，不是库存余额或库存估值。应收应付仍使用现有财务概览与计划页面。

日期按系统 Asia/Shanghai 时区处理，创建 / 更新时间按当地日界线筛选；预计日期为空的单据不纳入该日期口径。业务单据本身只有日期时不虚构小时精度。

区域与国家取客户 / 供应商当前档案，不自动推断国家所属大洲。历史空值显示「未填写」；应统一维护命名。产品类别使用当前主分类，不把附加分类重复计算进合计。负责人、来源、状态也使用当前档案，不是历史快照。客户增长报表按档案创建 / 更新日期统计，不是成交转化率。

## 在其他页面引用块

```vue
<script setup>
import ReportBlock from '../components/reports/ReportBlock.vue'
import { datePreset } from '../reports/registry'

const period = datePreset('year')
</script>

<template>
  <ReportBlock block-id="sales-country" :filters="period" />
  <ReportBlock
    block-id="purchase-supplier"
    :filters="period"
    :config="{ title: '供应商采购分布', view: 'donut', comparison: 'year' }"
  />
</template>
```

`frontend/src/reports/registry.js` 是预置块注册表，ID 是稳定引用入口。`ReportBlock.vue` 自行读取统计 API，包含加载、错误重试、过期请求取消、汇总、图表、表格与导出，不依赖报表中心页面。

`config` 支持 `title / source / group_by / grain / metric / view / date_field / comparison / filters`。`metric` 可为 `amount / count / quantity`，须与模块匹配。`filters` 属性通常传 `date_from / date_to / filter_<维度>`；`config.filters` 用于块内固定筛选，优先级最高。通过 `refresh-key` 主动刷新；`loaded` 事件返回结果，`drill` 事件返回选中维度以及原筛选上下文，调用页面决定如何继续分析。

## 服务端接口

- `GET /api/reports/catalog/`：模块、适用维度、日期口径、时间粒度。
- `GET /api/reports/data/?source=sales&group_by=country&date_from=2026-01-01&date_to=2026-09-11&comparison=year`：全量分组统计、去重总计、对比期间、增长率、口径、筛选摘要。
- 增加 `filter_customer=123`、`filter_region=华东` 等可组合筛选；空字符串表示「未填写」。实体型筛选使用 ID。
- 增加 `export=csv`：导出同一口径的完整分组、期间、筛选与去重合计，含 UTF-8 BOM 和文本公式注入防护。

`backend/crm/reporting.py` 集中负责统计，不修改交易、库存、权限或结算业务。保留当前开发身份约定，没有启用 RBAC；上线鉴权仍遵循项目既有完整验收要求。
