# 销售规则（最低报价数量）

## 使用

产品管理 → 打开产品详情 → 销售规则 → 新增规则。

白色电源示例：适用范围选“按参数条件”，颜色选择“白色”，最低报价数量填写 100，单位填写该 SKU 的单位 pcs，然后保存。也可直接选择单个白色 SKU。

支持编辑、启用、停用、开始日期、截止日期和备注。参数为空代表不限；全部参数留空代表该产品全部 SKU。同一参数的多个值按“或”匹配，不同参数按“且”匹配。

## 执行口径

- 使用报价日期判断规则是否生效，开始和截止当天均包含在内；留空表示不限。
- 每一报价行独立满足最低数量，不跨 SKU 或跨报价累计。
- 多条规则同时命中，全部须满足，相当于取最严格的最低数量。
- 单位必须与 SKU 单位一致，不自动换算。单位不一致会阻止报价并提示修正规则。
- 报价编辑实时提示，预览、保存及保存后导出前均校验；后端创建和迭代报价也执行同一校验。
- 当前版本数量不足时需修改数量，不提供特殊报价审批绕过。
- 已保存报价保留当时规则快照；更改规则不会改写旧报价。新增迭代按其报价日期重新匹配当前规则。
- 规则不改变 SKU 身份，不影响参数组合规则；供应商档案的采购 MOQ 仍独立管理。

## 实现

`SalesRule` 独立表；`rule_type` 当前为 `moq`，参数条件保存在 `filters`。客户、市场等条件尚未实现。

`/api/sales-rules/` 管理规则，按 `product` 查询；`/api/sales-rules/check-quote/` 预检。报价创建共用 `create_quote_items`，校验成功后写入报价行 `sales_rules_snapshot`。迁移为 `0061_sales_rules`。
