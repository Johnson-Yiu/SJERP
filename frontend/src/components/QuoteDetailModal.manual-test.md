# 报价工作台人工验收清单

- [ ] 打开一张报价，确认出现报价专用详情工作台，且没有“新增 SKU”按钮。
- [ ] 在“概览”确认客户、报价单号、状态、金额、有效期和快捷操作可见。
- [ ] 依次切换“报价明细、版本谱系、订单、重要备注”分页，内容正确且无空白错误。
- [ ] 在“版本谱系”点击原始报价或任一修订版，详情切换到所选版本。
- [ ] 点击“预览 PI”可打开所选版本 PI；点击“导出 Excel”下载同一版本的文件。
- [ ] 订单分页显示原始报价链全部订单，并在每条订单上显示其来源报价版本。
- [ ] 订单分页可打开订单详情，并可预览其来源报价版本的 PI。
- [ ] 在修订版新建富文本重要备注；回到原始报价确认备注仍显示来源版本、创建人和时间。
- [ ] 标记备注为不再生效，二次确认后正文显示删除线且记录没有消失。
- [ ] 点击“转为订单”后，订单草稿带入客户、商品、数量、单价、币种、汇率、运费、折扣和备注；取消不创建订单，保存后来源报价显示“已接受”。
- [ ] “版本谱系”中的“预览 PI”可打开该条版本的 PI；“查看详情”可切换到该版本的工作台。
- [ ] “概览”的版本摘要为各版本展示单号、版本名称、报价日期、状态、金额和“预览 PI / 查看详情”操作。
- [ ] “重要备注”默认只显示“新增备注”；点击后才展开富文本编辑器，“取消”后恢复隐藏状态。
- [ ] “转为订单”为白底深绿字；点击后在报价管理的当前页面上居中打开浮动订单草稿，关闭后不跳转到订单管理。
